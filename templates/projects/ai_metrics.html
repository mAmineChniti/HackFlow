How to reproduce the demo

  1. Sign in as the organizer or admin demo account.
  2. Open a project and run Evaluate with AI; in async mode the HTTP response is 202 and the UI polls the status endpoint.
  3. Refresh this page to see the new p50/p95 call in the live table.
  4. Run python manage.py ai_benchmark for the same classifier and rubric metrics from the terminal.

The labelled set is a small, hand-built validation set, not a production benchmark. Re-measure accuracy and latency on new submissions before making quality claims. The metrics buffer contains no project descriptions, prompts, API keys or user data.
